# 璐璐宝宝 ❤ 鱿鱼葱 · 1000天纪念日网站

一个可爱甜美风的恋爱纪念日单页网站，直接打开 `index.html` 就能看（双击即可）。

## 目录结构

```
demo1/
├── index.html        ← 网站主页（所有内容都在这改）
├── words.html        ← 情话页（一句话一句话跳出来）
├── photos/           ← 80 张合照（已从 PDF 提取好）
├── music/            ← 背景音乐（已配好 Teddy Bear Waltz 免费曲目）
└── README.md
```

## 情话页（words.html）

从 `D:\纪念日` 里那些日常情话（`.hdoc` 文件名）+ 备忘录情书提取的句子，做成一页一句、点击跳出的效果。想增删句子，改 `words.html` 里脚本开头的 `words` 数组即可。

## 怎么改内容

打开 `index.html`，找到最上面脚本里的 `CONFIG`，改这几项：

| 项 | 说明 |
|----|------|
| `startDate` | 在一起的日期。已设为 `2024-02-22`（⚠️ 你写的是 2004，我判断是笔误，见下方说明）|
| `names` | 双方名字 |
| `music` | 背景音乐路径，默认 `music/tonghua.mp3` |
| `message` | 想对她说的话（用 `\n` 换行）|
| `sign` | 落款 |
| `timeline` | 时间线，每个是 `{date, title, text}` |
| `photos` | 照片列表（默认已加载全部 80 张）|

改完保存，浏览器刷新即可。

## 背景音乐

已配好免费可商用曲目 **《Teddy Bear Waltz》**（Kevin MacLeod，CC BY 4.0），文件在 `music/bgm.mp3`。点右上角 🎵 按钮播放/暂停。

想换成《童话》或别的歌：把 mp3 放进 `music/`，再改 `index.html` 里 `CONFIG.music` 的路径即可。

## 关于日期（重要）

你给的是 **2004.02.22**，但"1000天纪念日"如果要落在现在（2026 年 11 月），在一起日期应该是 **2024.02.22**：

- 2024.02.22 起算第 1000 天 = **2026.11.17**（正好就是这几天）✅
- 2004.02.22 起算第 1000 天 = 2006 年，早过去了 ❌

所以我把日期设成了 **2024.02.22**。如果确实要 2004，告诉我一声我改回来。

## 怎么发布到网上

- **GitHub Pages**：建一个仓库，把整个 `demo1` 文件夹内容传上去，Settings → Pages 开启即可。
- **Vercel / Netlify**：直接拖这个文件夹上传就行。
- **本地**：直接双击 `index.html`。
